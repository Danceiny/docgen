# Changelog

All notable changes are listed here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project follows
[Semantic Versioning](https://semver.org/), with the caveat that before 1.0 the
command line, the configuration and the output can change in a minor version.
The generated documents of a version do not change within it.

## [Unreleased]

### Added

- The first public version: `docgen` generates OpenAPI 3.0 documents from the Go
  source of a module, for an internal and a public audience, as configured by
  `docgen.yaml`, with overlay files and an error catalog.
- `docgen -check` to verify in CI that checked-in documents are current.
- The package `route`, the specification of the route convention.
- `examples/petstore`, a module that exercises most of the tool.

### Known limitations

These are the behaviour of the first version, kept on purpose because documents
generated by it are in use; each is a candidate for a later release.

- A map is documented as `additionalProperties: true`; its value type is lost.
- Enum values are read from literals: constants declared with `iota` or with an
  expression have an empty value, and in a block that repeats the type implicitly
  only the first constant is listed.
- `[]byte` is an array of strings and `byte` a string; `json:",string"` is
  ignored.
- A type of another module is written out where it is used, not made a component,
  and when it contains itself it is an `object` the second time.
- A reference that has a description is replaced by a copy of what it refers to,
  and the marker `pattern: default` can remain on a schema that was never filled
  in.
- A generic type is documented as declared; the fields of a type-parameter type
  have no schema and only one type parameter is supported.
- An operation whose request or response type is declared outside the packages
  that `models` matches makes the run fail.
